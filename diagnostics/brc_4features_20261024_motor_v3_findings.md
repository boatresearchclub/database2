## 新TimeX v3 / HTTP 422
ステージングWorkerのコードでは、次の異なる事象が同じ 422/unavailable になる場合がある：
1. JSTの日付不一致
2. KVの同一レース情報未保存・構造不一致
3. 内部展示サービスが非200またはJSON形式不正
4. TimeXのモデル入力・計算・正規化の失敗
ネットワーク接続例外や構成不足は別ステータス（503等）になり得る。

2026-10-24 無認証GETだけの観測：
- ステージングWorkerの認証境界：認証必須
- コンテキスト存在確認：無認証ではKVの実内容を確認不可

- 公式B番組と開催情報：14会場168Rの照合に成功、READY_FOR_STAGE、送信は0件
したがって、公開展示APIが応答することは判明したが、認証済みv3の422原因とKVの内容はまだ確定していない。

次のステージング限定作業：
- CloudflareのKV namespace名とWorkerバインディング名を区別して確認。JavaScriptコードが参照するバインディング変数名は BRC_RACE_CONTEXT。KV namespaceのリソース名 BRC_RACE_CONTEXT_STAGE と同じ名前である必要はないが、実際のバインディング設定の一致は必要。
