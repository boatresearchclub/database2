# BRC Tide V12 — 事前1着率・管理者研究統合（検証ブランチ）

このブランチは `main` と分離した研究用です。本番反映・一般会員への確率変更は行いません。

## 対象
- BRC Worker の展示前1着率 `basePctFloat` のみをベースに潮汐補正後の研究値を独立計算します。
- `pctFloat`（展示反映後）や既存の `basePctFloat` 自体は書き換えません。
- 管理者画面でのみ補正前後の比較と事前予測のCSV記録を表示します。
- 2021〜2025年の潮汐別「イン逃げ率」集計に基づく試算です。「1コース1着率」とは異なります。

## GitHubでの組み込み
`.github/workflows/brc-tide-v12-staging.yml` が**この研究ブランチ上のみ**で `research/tide-v12/build_BRC_TIDE_V12_INDEX.py` を実行し、`index.html` の末尾に5つの研究用スクリプトを埋め込む設計です。元の `main` に書き込む処理はありません。GitHub Actionsが無効な場合は実行されません。

## 導入の前提と制限
- 管理者画面での表示動作・当日潮汐APIの通信・公式結果との一致・実レースの精度向上は本番サイトで未確認です。
- APIのCORS制限・観測地点コードの不一致・時刻近辺での潮汐局面変化時は補正を表示しない想定です。
- 事前1着率を保存するlocalStorageは端末依存です。サーバー側に保管されるわけではありません。
- **このブランチはそのままmainへマージしないでください。** 事前の実機検証と予測評価が完了してから本番採用を判断します。

## 事後確認
研究ブランチのINDEX内に `BRC_TIDE_PRE_V12_START_20261023` と `BRC_TIDE_PRE_V12_END_20261023` が各1回あること、一般会員で研究パネルが出ないこと、既存の1着率が変更されないことを確認します。
